# RGB TTT mod database

Maps in this folder are installed automatically by RGB TTT on launch.

## Credits

All three maps are ports of Garry's Mod Trouble in Terrorist Town maps. All credit for the level design goes to the original creators; the maps were converted to Unity for RGB TTT. Original content (textures, models) belongs to its respective owners (Valve / the map authors).
